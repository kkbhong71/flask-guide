01

프로젝트 폴더 생성 및 파일 준비

올바른 폴더 구조가 배포 성공의 핵심

📁 폴더 구조

프로젝트 폴더를 만들고 아래 구조로 파일을 배치합니다.

kkb-프로젝트명/ ├── app.py ← Flask 서버 (백엔드) ├── templates/ │ └── index.html ← 반드시 이 폴더 안에! ├── static/ ← CSS, JS, 이미지 (선택) ├── requirements.txt ← 패키지 목록 ├── render.yaml ← Render 배포 설정 └── runtime.txt ← Python 버전 지정

📄 필수 파일

requirements.txt

requirements.txtFlask==3.0.0
gunicorn==21.2.0

render.yaml

YAMLservices:
  - type: web
    name: 프로젝트명
    runtime: python
    buildCommand: pip install -r requirements.txt
    startCommand: gunicorn app:app --bind 0.0.0.0:$PORT
    envVars:
      - key: PYTHON_VERSION
        value: 3.11.7

runtime.txt

runtime.txtpython-3.11.7
🚨
가장 흔한 실수!index.html을 templates/ 폴더에 넣지 않으면 TemplateNotFound 에러 발생
02

터미널 열기 및 Git 초기화

프로젝트 폴더에서 Git을 설정합니다

⌨️ 터미널 열기

프로젝트 폴더에서 우클릭 → "터미널에서 열기"

PowerShellcd C:\Users\USER\Desktop\developer\Web_app_development\kkb-프로젝트명

🔧 Git 초기화 및 첫 커밋

PowerShellgit init
git add .
git commit -m "프로젝트명 v1.0 초기 커밋"
git branch -M main
명령역할
git init폴더를 Git 저장소로 초기화
git add .모든 파일을 추적 대상에 등록
git commit파일을 하나의 저장 단위로 묶기
git branch -M main브랜치 이름을 "main"으로 설정
⚠️
순서가 중요합니다!반드시 add → commit → branch 후에 push
❌ 잘못된 순서
git init
git remote add origin ...
git push -u origin main  ← 에러!
✅ 올바른 순서
git init
git add .
git commit -m "초기 커밋"
git branch -M main
git remote add origin ...
git push -u origin main  ← 성공!
03

GitHub Repository 생성

코드를 올릴 빈 저장소를 만듭니다

🐙 새 저장소 만들기

  1. github.com/kkbhong71 접속
  2. 우측 상단 "+" → "New repository"
  3. Repository name 입력 (예: peer-observation)
  4. Public 또는 Private 선택
  5. Create repository 클릭
🚨
README, .gitignore, license 모두 체크 해제!빈 저장소로 만들어야 합니다. 체크하면 로컬과 충돌 발생

🔗 원격 저장소 연결

PowerShellgit remote add origin https://github.com/kkbhong71/프로젝트명.git

remote origin already exists 에러 시:

git remote remove origin
git remote add origin https://github.com/kkbhong71/프로젝트명.git

06

GitHub Pages로 정적 사이트 배포

HTML 파일을 무료로 호스팅하여 누구든 접근 가능하게 합니다

🤔 Render.com과 GitHub Pages, 언제 어떤 것을?

두 가지 배포 방식은 용도가 다릅니다. 상황에 맞게 선택하세요.

구분Render.comGitHub Pages
용도Flask 서버가 필요한 웹앱HTML 파일만 보여주기
필요 파일app.py, requirements.txt 등index.html 하나면 충분
서버Python 서버 실행서버 없음 (정적 호스팅)
DB 저장SQLite / PostgreSQL 가능불가능 (읽기 전용)
비용무료 (제한 있음)완전 무료
속도15분 비활성 후 느려짐항상 빠름
적합한 예시동료장학 관리 시스템, 방과후 신청가이드 문서, 포트폴리오, 소개 페이지
💡
쉽게 기억하기
데이터를 저장해야 하면 → Render.com (Flask)
데이터를 보여주기만 하면 → GitHub Pages (HTML)

📋 GitHub Pages 배포 절차

아래 4단계를 따라하면 HTML 파일을 웹에 공개할 수 있습니다.

Step A. 새 GitHub 저장소 만들기

  1. https://github.com/kkbhong71 접속
  2. 우측 상단 "+" → "New repository" 클릭
  3. Repository name 입력 (예: flask-guide)
  4. ⚠️ Public 선택 (GitHub Pages 무료 사용 조건)
  5. README 등 체크 해제 (빈 저장소) → Create repository
⚠️
반드시 Public!
Private 저장소는 GitHub Pro 유료 플랜에서만 Pages 사용 가능합니다.

Step B. 파일 이름을 index.html로 변경

GitHub Pages는 기본적으로 index.html이라는 파일을 찾습니다.

Flask_웹앱_배포_가이드.html → index.html ← 이름 변경 필수!

프로젝트 폴더 구조:

flask-guide/ └── index.html ← 이 파일 하나만 있으면 됨!
💡
Render.com과 달리 app.py, requirements.txt, templates/ 폴더 등이 전혀 필요 없습니다. HTML 파일 하나면 충분해요!

Step C. Git Push

프로젝트 폴더에서 우클릭 → "터미널에서 열기" 후 실행:

git init
git add .
git commit -m "GitHub Pages 배포"
git branch -M main
git remote add origin https://github.com/kkbhong71/flask-guide.git
git push -u origin main

Step D. GitHub Pages 활성화 ⭐ 핵심!

이 단계가 Render.com 배포와 가장 다른 부분입니다.

  1. GitHub 저장소 페이지에서 Settings 탭 클릭
  2. 왼쪽 메뉴에서 Pages 클릭
  3. Source 항목 설정:
    　Branch: main
    　Folder: / (root)
  4. Save 클릭
✅
약 1~2분 후 접속 가능!
https://kkbhong71.github.io/flask-guide/
이 URL을 학생이나 동료 교사에게 공유하면 누구든 바로 접속할 수 있습니다.

📝 이후 내용 수정 시

index.html을 수정한 후 아래 3줄만 실행하면 자동 반영됩니다.

git add .
git commit -m "내용 수정"
git push

Render.com과 동일한 방식이에요! Push하면 약 1분 후 반영됩니다.

🗂️ 여러 페이지 추가하기 (응용)

나중에 페이지를 더 만들고 싶다면, 같은 저장소에 HTML 파일을 추가하면 됩니다.

flask-guide/ ├── index.html ← 메인 페이지 ├── git-guide.html ← /git-guide.html 로 접속 └── render-guide.html ← /render-guide.html 로 접속

접속 URL 예시:

https://kkbhong71.github.io/flask-guide/              ← index.html
https://kkbhong71.github.io/flask-guide/git-guide.html ← 추가 페이지

에러 대응 가이드

자주 발생하는 에러와 즉시 해결법

src refspec main does not match any

원인: commit 없이 push 시도
git add .
git commit -m "초기 커밋"
git branch -M main
git push -u origin main

TemplateNotFound: index.html

원인: index.html이 templates/ 폴더 밖에 있음
mkdir templates
move index.html templates\index.html
git add .
git commit -m "templates 폴더 구조 수정"
git push

Internal Server Error (500)

원인: Render Logs 탭에서 에러 메시지 확인
# 흔한 원인:
# 1. Python 버전 → PYTHON_VERSION=3.11.7 설정
# 2. DB 경로 → /tmp/ 경로 사용
# 3. 패키지 누락 → requirements.txt 확인

remote origin already exists

원인: 원격 저장소가 이미 등록됨
git remote remove origin
git remote add origin https://github.com/kkbhong71/프로젝트명.git

💡 참고: SQLite 주의사항

Render.com 무료 플랜에서 SQLite 사용 시, 서버 재시작(약 15분 비활성 후) 시 DB 초기화 가능. 실제 운영에서는 PostgreSQL 전환 권장.
